# Phase 2 — Next time, finishing, and calm progress

Keep the Expo/React Native app and current database-backed accounts. Replace everyday weight planners with one shared rule helper, using all sets from the most recent workout for the same exercise/equipment. Easy adds 5 lb/2.5 kg; Easy squat/deadlift/leg press adds 10 lb/5 kg. Good or unanswered adds 5 lb/2.5 kg only when every set reaches eight reps. Hard holds. Use the heaviest completed weight as the baseline; mixed feedback uses the hardest feedback. Zero-weight work stays zero. No history shows no suggestion. Use it on Progress opens a fresh local workout and fills its first set; Use it in the logger updates only the first set.

On successful completion, navigate to an owned saved-workout finish route. Show Nice work, an approximately one-second check animation, total external weight times reps, sets, measured duration, new heaviest-weight badges per exercise and calendar-week completed-workout count. Updating an already completed workout does not trigger a new celebration. Preserve the existing Share with friends On/Off choice: automatic sharing stays on only when chosen. The finish action opens shared activity or explicitly shares a private workout; private workouts remain private unless that action is chosen. Backend checks sharing preferences and ownership, and serializes feed publication to avoid duplicate cards.

Progress overview is an exercise chooser. Each exercise has a focused page: big Best lift, a grouped line chart, one next-time sentence, expandable history. Remove all weight grids. Use a light background, one green accent, whitespace, readable 16px minimum text and 44px controls. Ask lb/kg once for new users, persist the choice, preserve existing users' units.

Structure: shared/next-weight.ts and tests own the rule; components/lift-log/next-weight-line.tsx owns its sentence and Why help; app/workout/[id].tsx applies it; app/exercise/[id].tsx owns focused progress; app/finish/[id].tsx owns the finish moment; server/db.ts + routers.ts return owned finish summaries and explicit sharing; additive schema fields persist duration and first-run unit selection.
